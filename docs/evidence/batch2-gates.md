# 第二批约束说明

## 高相似原文作答

`server/config.json` 里 `faq_shortcut` 默认是 `false`。关掉时，网关仍使用编排返回的回答，并检查 `[n]` 是否对上已检索到的引用卡。

打开之后，只有检索分不低于现有引用阈值、并且也不低于 `faq_shortcut_score`（默认 0.85），同时片段里能对上知识库条目标题时，才改用该条原文，并带上这一条引用。它不另建检索，也不改知识库。

默认先不要打开。要先用开发集看误召回：标题被片段带出来、但问题其实问的是别的事。看完再决定是否把默认改成打开。这一项会改 C 组回答文本，所以未验证前不参与默认路径。

## 期望证据片段

`tests/eval/test-set.json` 里一部分库内题有 `expected_span`。跑分时如果带了这个字段，结果里会多一个 `span_observed`，汇总进 `span_observation`。它只看这段原文是否出现在回答或引用里，用来发现「标题对了、片段偏了」。

它不写入 A/B/C 的六项主指标，也不改变这道题通过或不通过。
