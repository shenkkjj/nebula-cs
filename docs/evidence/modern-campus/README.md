新版保存在本地仓库，发布待安排。以下画面来自浏览器访问真实的本地应用，使用样例知识库和隔离的测试数据库。此前确认的 E5 / S1 原型仍可在运行中的 `/design/` 查看。

## 回归结果

- `python -m unittest discover -s tests` 通过 110 项测试，覆盖工单重复提交、坐席竞争接入、访客工单分页和隔离、近七日评价统计。
- `node --check` 通过门户、坐席、后台和登录四个入口脚本的语法检查。
- Chrome 157 验证桌面与 390 px 手机视口。浏览器实测了流式问答、出处与历史恢复、澄清、拒答和评价，也验证了申请人工、坐席接入与回复、结单及刷新后的工单状态。
- 同一轮浏览器测试验证了角色权限、管理后台统计、知识库回写和坏例记录。测试期间浏览器没有未捕获的 JavaScript 异常，也没有发起第三方请求。
- 「我的工单」通过 Chrome 测试。访客在提交工单的浏览器里切换对话后，可查看等待、处理中和已结束的工单及人工回复。保留对话历史时可返回原对话。用另一个浏览器身份请求同一张工单时返回 404。弹窗验证了 320 至 700 px 的窄屏布局。

## 资源对照

现代校园版首次改造后，在 Windows 上用同一个 Python 3.13.5 进程配置对照 `2f8cd10` 与新版。两者均以 `ENGINE=campus` 启动，使用全新的临时 SQLite 数据和同一份 144 段的样例知识库。外部模型与向量服务未启用。交替执行三轮，每轮用四个并发客户端发出 40 次知识库问答及配套的门户状态查询。RSS 取服务进程的工作集，表中填写三轮中位数。轮询数据量为已读取十条坐席回复后、工单无新消息时的单次 HTTP 响应体大小。

| 指标 | 改造前 | 新版 |
| --- | ---: | ---: |
| 就绪后空闲 RSS | 34.27 MiB | 32.86 MiB |
| 短测采样峰值 RSS | 34.52 MiB | 34.30 MiB |
| 问答响应时间 P50 | 25.85 ms | 25.58 ms |
| 访客工单无更新轮询 | 1,852 B | 162 B |
| 坐席工单详情无更新轮询 | 2,373 B | 370 B |

新版轮询通过消息和判定游标省去重复的数据。本表为本机的小样本对照，云端内存和并发容量仍待发布环境验证。
