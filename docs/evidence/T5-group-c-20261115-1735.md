C 组达标的是库外拒答、误拒率和重复引用（按文档合并后同一文件只留一张卡）。范围内正确率和 Hit@3 未达标，主要受关键词检索排序影响：正确条目经常不在最前，引用卡展示的是同一文档里分数最高的片段，不一定是作答依据那一条。首字 p50 略高于 3 秒目标。

这些数字不能当成 A 组或 B 组。C 组没有整体达标。
