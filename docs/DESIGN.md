# 校园客服 · DESIGN

- **版本 / 日期**：v1.0 | 2026-11-14 · 已整版确认
- **对应 PRD 版本**：PRD v1.0 · R-101–R-107（门户）、R-201–R-205（约束层）、R-301–R-305（坐席）、R-401–R-404（后台）、R-501–R-504（评测）
- **原型入口**：`docs/design/` 下 `portal-states.html`（门户新状态）、`staff.html`（坐席与后台）；或运行门户后访问 `/design/`

## 1. 方向选择与取舍

- **采用方案**：候选 S1「值班台」——坐席和管理员各用一个应用。坐席是三栏同屏处理（队列｜对话｜判定与操作），后台是左侧导航加密集表格。门户沿用 E5（2026-11-07 已确认），新增澄清选项、坐席回复、知识库维护三种状态。
- **选择理由**：坐席处理最直接（选中工单就能回复、回写、标坏例，不用跳页）；后台像常见管理系统，表格信息密度高；自定义部件少，实现最省事。
- **已淘汰候选**：S2「控制室」——统一入口、状态优先、流水线追溯突出。优点是约束层可见性强（首页红绿灯、处理页横向步骤条），适合答辩演示；缺点是坐席多一次点击、自定义部件多。2026-11-14 候选对比后用户选定 S1，S2 原型已删除。

## 2. 界面布局与设计变量

- **目标视口与输入方式**：门户桌面宽 ≥ 1280px（PRD §1 承诺 H1），坐席与后台 ≥ 1280px，键盘可达所有交互，焦点可见。不适配手机。
- **核心变量与层级**：E5 黑金视觉合同不变（`--ink` 系深色背景、`--champagne` / `--gold` 为主色、`--font-display` Cormorant Garamond、`--font-body` Manrope）。坐席与后台新增状态色：`--ok` 绿、`--warn` 琥珀、`--bad` 赭红、`--info` 钢蓝，只表达状态不作装饰。字号 14px 正文、13px 表格、11-12px 辅助。
- **导航与入口**：门户单页应用，顶栏品牌 + 新对话；坐席工作台独立应用（`/agent`），顶栏 + 三栏布局；管理后台独立应用（`/admin`），左侧导航（知识库文档、绑定自检、审计日志、约束参数、评测）。登录页（`/login`）区分坐席 / 管理员。
- **关键状态与流程**：
  - 门户：正常问答（chips → 输入 → 流式回答 + 引用卡）｜澄清（机器人给 2-3 个候选 chip）｜拒答 + 转人工按钮｜人工接入（顶栏「人工接入中」、消息标「人工客服」）｜知识库维护（顶栏黄色「知识库维护中」、页面顶部通知条、新问题自动建工单）
  - 坐席：队列三态（待接入｜处理中｜已结束）→ 点卡片 → 三栏（左队列｜中对话 + 回复框｜右判定详情 / 回写 / 标坏例三 tab）→ 结束工单弹层（必填处理说明）
  - 后台：左侧导航 + 主区表格 / 表单。审计日志可展开行看追溯；评测页列三组对照、可运行、可导出 MD/CSV
- **响应式与降级**：1280px 以下三栏变两栏（判定面板到下方），≤ 760px 单栏。`prefers-reduced-motion: reduce` 时动画直接跳终态。Google Fonts 加载失败回退到 Noto Serif SC / PingFang SC / Microsoft YaHei。
